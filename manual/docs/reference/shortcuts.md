# Keyboard and mouse

On a Mac, <kbd>Cmd</kbd> in place of <kbd>Ctrl</kbd> throughout. Single-key shortcuts are ignored while you are typing
in a field.

## Anywhere

| Keys | Does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>1</kbd> / <kbd>Ctrl</kbd>+<kbd>2</kbd> | The province / the workbench |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Settings (desktop app) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> | Reload the window (desktop app) |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | Quit (desktop app, Linux and Windows; <kbd>Cmd</kbd>+<kbd>Q</kbd> on a Mac) |
| <kbd>Ctrl</kbd>+<kbd>0</kbd>, <kbd>Ctrl</kbd>+<kbd>+</kbd>, <kbd>Ctrl</kbd>+<kbd>−</kbd> | The window's zoom: actual size, larger, smaller (desktop app) |
| <kbd>F11</kbd> | Full screen (desktop app; <kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+<kbd>F</kbd> on a Mac) |

## The province

| Keys | Does |
|---|---|
| <kbd>Space</kbd> | Play / pause |
| <kbd>1</kbd> … <kbd>9</kbd>, <kbd>0</kbd> | Speed: real time, 10×, a minute, ten minutes, an hour, a day, a week, a month, a year a second; thirty years a minute |
| <kbd>Esc</kbd> | Close what is open on top (the scene controls, then Settings or Help, then the analytics drawer); otherwise step out a level (person › house › settlement › city › province); otherwise clear the selection |
| <kbd>F</kbd> | Follow the selected person, or stop |
| <kbd>[</kbd> / <kbd>]</kbd> | The left panel / the inspector |
| <kbd>L</kbd> | The legend |
| <kbd>?</kbd> | Help |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd>, arrows | Move the map |
| <kbd>=</kbd>, <kbd>−</kbd> (and the numpad's) | Zoom the map in and out |

With the numpad's NumLock on, its digits also change the speed.

## The map, with the mouse

| | |
|---|---|
| Wheel | Zoom about the cursor |
| Drag (any button) | Move the map |
| Click | Select a person, a house (its household) or a building; on a person talking, close up, the conversation; on empty ground, clear the selection |
| Double-click a building | Drop into it |
| Double-click a person | Follow them |
| Hover | Who or what is under the cursor |

## The 3D close-up

The mouse and keys work as in Unreal Engine's editor viewport. In brief:

| | |
|---|---|
| Right button, drag | Look about |
| Left button, drag | Move along the ground, and turn |
| Middle button, or left and right | Slide sideways and up and down |
| <kbd>Alt</kbd> or <kbd>Ctrl</kbd> + left / right / middle | Orbit / dolly / track about what the camera looks at |
| Wheel | Dolly toward the ground under the cursor |
| Wheel with a button held | Camera speed ×1.1 a notch |
| With a button held: <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd>, <kbd>E</kbd> <kbd>Q</kbd>, <kbd>R</kbd> <kbd>F</kbd>, <kbd>C</kbd> <kbd>Z</kbd> | Fly; up and down; up and down the camera's own way; the lens |
| Arrows, <kbd>PgUp</kbd> <kbd>PgDn</kbd>, numpad | Fly without a button |
| <kbd>Home</kbd> | Level the view |

[The 3D close-up](../province/3d.md#moving-about) has the full tables, and the game controller's.

## The workbench

| Keys | Does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Run the file in front |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> | Stop the run |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Save / save all |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Close the file (or middle-click its tab) |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Show or hide the explorer |
| <kbd>Ctrl</kbd>+<kbd>J</kbd> | Show or hide the Console and Problems |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | New province file (desktop app) |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open a folder (desktop app) |

In the editor, the usual editing keys of VS Code's editor (Monaco) apply: <kbd>Ctrl</kbd>+<kbd>Space</kbd> to complete,
<kbd>Ctrl</kbd>+<kbd>F</kbd> to find, <kbd>Ctrl</kbd>+<kbd>/</kbd> to comment a line, <kbd>F1</kbd> for its command palette.
